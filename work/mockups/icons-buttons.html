Icons & buttons: audit and upgrade options

Every icon below is the real Lucide path from node_modules, drawn at the size and stroke each option specifies. The 1× strips copy four live surfaces: the chat card header, the browser toolbar, message actions and the composer. The 2.5× row uses CSS zoom, so it is re-rendered rather than stretched, and shows rest, hover, pressed, toggled on, focus and disabled. Hover the live buttons too.

14distinct icon sizes in TSX (11–20px), chosen per call site. The chat header alone mixes 17/1.6, 17/1.8 and 16/1.8, and its window controls use 14, 11 and 14.
13stroke widths (1 to 3, plus Lucide's default 2 on most icons). Stroke scales with size, so a 13px icon is visibly lighter than a 17px one next to it.
8button heights in CSS (20, 22, 24, 26, 28, 30, 32 and 34px) and 12 corner radii (2–14px, with 4, 5, 6, 7, 8, 9 and 10 all in use).
1icon library (Lucide, 94 icons), which is good. The drift is in how it's used, not the source. Hover and focus recipes vary by surface: some use an outline ring, some a background, some nothing.
