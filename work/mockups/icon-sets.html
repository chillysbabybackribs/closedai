New icon set: candidates for an expensive, new-Mac feel

SF Symbols is the real "new Mac" look, but Apple licenses it only for apps on Apple platforms, so it can't ship in this Linux Electron app. These are the open-licence sets closest to that feel. Every set below is drawn in the same live surfaces with identical button styling, so only the icons differ. The bottom row of each set shows all 16 glyphs at 2× so you can judge the craft: corner rounding, terminals and optical balance. Icons are the actual files from each project, fetched through Iconify.
