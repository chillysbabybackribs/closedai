ClosedAI Proposed Design

Adopted identical visual language: clean pill categories, capsule search, spacious list rows, subtle category glyphs, technical metadata, and inline inspector.

1. Default State: Clean Spacious List & Capsule Search

Full overview showing the pill filter navigation, token cost telemetry, and calm list items without any distracting card borders.

2. Expanded State: Inline Technical Inspector

When a tool row is clicked, it opens an inline card detailing parameters, error telemetry, prompt excerpt, and repair draft trigger without shifting unrelated rows.
