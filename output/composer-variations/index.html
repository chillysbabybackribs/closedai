Composer variations · round 2

Variation 01 is in trash/. 02 and 03 stay as the reference shell. Below are five new concepts that each answer one question: what is the Agent chip, once it stops being a mode? Every element maps to something ClosedAI actually has: four providers, tool namespaces, one folder, an assigned browser tab, peer chats, sandbox, context budget.

04Agent card · the chip is a builder

The Agent chip names a saved agent: a brain, a set of hands, a reach, and guardrails. Press it and the composer's top region becomes the builder. While a turn runs, the same chip becomes the viewer and shows what the agent is doing right now. One control, three faces.

05Loadout · the agent is what you slot in

07Prompt line · the agent is the shell prompt

The most rugged shape: a terminal prompt whose prompt string is the agent's identity. User, folder, agent bracket, then the cursor. Every token is a control. Slash opens completions for skills and composer commands, at attaches tabs and chats, up arrow recalls history. Status is a footer line, not chrome.

08Switchboard · capabilities as rockers, dangerous ones need arming

The agent is defined by what it may do, shown as physical switches above the field. Files, browser, search, and sandbox are ordinary toggles. Native instrumentation and the credential vault cannot be left on: they arm for one turn, glow amber, and disarm when the turn ends. Run reads the board and says so.
