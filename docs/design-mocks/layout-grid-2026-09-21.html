Grid layout option

Proposal: keep the current customisable layout as the default ("Custom"), and add a View → Layout option that arranges the visible chats into a balanced grid chosen for the canvas size, plus a "New chat grid" submenu that creates 4/6/8/10 chats and arranges them. Every workspace below is rendered to scale from the real numbers: 14 px dividers, 300 × 280 px hard minimum, and a 440 px "comfortable" chat width. Tile labels show the resulting size in px.

2 · Your screen (1920 × 1048), browser docked right at its current 40 %

"Arrange chats in grid" with 4, 6, 8, and 10 visible chats. The browser keeps its side and width; only the chat subtree is rebuilt. Column/row counts are chosen by the same function for every case (largest comfortable tile, then fewest empty cells).

3 · Same screen, browser hidden (globe button)

The chat subtree reflows into the full canvas. Nothing about the browser's saved position changes; showing it again puts it back at 40 %.

4 · Six chats across screen sizes

Same command, same six chats. Frames are scaled to the same width so the relative tile size is visible. This is why fixed presets are the wrong shape: 6 chats is a 3 × 2 grid on your screen but a 2 × 3 stack on a portrait/tall canvas, and comfortable on 1440p/4K only.

5 · First-open default when a project has no saved layout

Today: always one chat + browser. Proposed: pick by window width. This only applies before you've arranged anything, so it never touches a saved layout.
