Zoomable docking workspace — concept

HTML/CSS concept (not image-generated), using the live warm-chat theme tokens and the direction-C tab header. It adds one strip, the frame bar, above the existing split-tree canvas. Every tile below is an ordinary chat-layout pane; the new parts are named subtrees, zoom levels, saved frames, icon-card collapse and floating windows.

Release notes

Pulling a tab past the edge of its tile floats it: a real window above the canvas, still live. Hovering a tile shows the dock compass: edges split that tile and the centre adds the chat as a tab. The live preview uses the existing layout-drag-preview path. The dashed bands dock across the full width of the current zoom root, so docking across the bottom while zoomed into Research docks inside Research. Dropping on the gutter leaves the tile floating.

Double-click a tile headerZoom into that tile. This is today’s solo mode, now recorded in history.
Double-click the gutterZoom out one level; at level 0, toggle to the overview.
