Tools menu → Agent / Developer, and the rebuilt Tools dialog

Three parts. (1) The title bar menu regrouped by who the item serves. (2) The Tool configuration dialog as a two-level browser: namespaces on the left with master switches, the selected namespace's tools on the right with descriptions, verbs, and a provider filter. (3) The same dialog's This chat view, answering "what was this pane actually given?".

One card per tool. A plain-English name, a one-line description written for a person (not the model's schema text), and a switch. Hovering a card shows the technical id and a longer explanation of what "off" changes. Namespaces are just small section labels in the grid. Action tools (page, script, …) are one card each; their verbs are not exposed.
