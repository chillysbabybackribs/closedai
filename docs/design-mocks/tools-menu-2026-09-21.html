Tools menu → Agent / Developer, and the rebuilt Tools dialog

Three parts. (1) The title bar menu regrouped by who the item serves. (2) The Tool configuration dialog as a two-level browser: namespaces on the left with master switches, the selected namespace's tools on the right with descriptions, verbs, and a provider filter. (3) The same dialog's This chat view, answering "what was this pane actually given?".

A row is a name and a switch. A small dot and a short note on the right flag the rows worth opening: amber for a suggestion, red for errors. Clicking a row drops down its overview: technical id, what it does and what off changes, effect, cost, last use, errors, the exact text the model reads, and the actions (send to chat for repair, show schema). One overview open at a time. Groups keep their sentence, badge, cost, and master switch.
