Three parts. (1) The title bar menu regrouped by who the item serves. (3) The same dialog's This chat view, answering "what was this pane actually given?".

Groups are effects, not namespaces. Each group is a trust decision with one switch and a badge: reads only, acts as you, controls the app, reads secrets, runs native code. The header and each group show what the advertised schemas cost per turn, computed from the manifest. Notes like “never used” and “3 errors” appear only when non-zero. Hover gives the technical id, what off changes, and the exact text the model sees. Presets in the footer: Full, Read-only, Custom. Hints under a row are the only place telemetry appears: last use and cost on every row that has history; “suggested off” with a one-click Turn off when a tool is unused for weeks and costs real tokens; recent errors with Send to chat for repair, which drops the tool’s id, counts, and last error messages into the selected chat’s composer. The banner at the top applies all suggestions at once.
