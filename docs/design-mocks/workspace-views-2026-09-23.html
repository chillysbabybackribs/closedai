Workspace views as tabs

Any tile can hold chats and views side by side. A view is a tab with a kind, not a chat and not a dialog: same strip, same drag, same close, same split. The only new control is the "+" menu, which grows from "new chat" into "new chat or open a view". Rendered from the warm theme tokens.
