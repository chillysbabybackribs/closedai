Hive workstation

Design for a multi-provider coordinated agent fleet inside ClosedAI. Visual language matches the existing dark shell (#181818 canvas, #8ab4f8 accent) and maps to shadcn/ui New York primitives already in the repo (Button, Card, Badge, Table, Tabs, Input, Dialog, ScrollArea, Progress, Separator, Tooltip, Collapsible, Switch). Entry: View → Hive workstation or a layout preset that swaps the chat grid for this surface while keeping the shared browser dock optional.

Information architecture

  • Runs (left): one hive job per repo task; resume/history.
  • Board + graph (center): units of work, not chat tabs.
  • Inspector (right): conductor thread + selected unit detail.
  • Status bar: per-provider capacity (the multi-subscription wedge).

shadcn mapping

  • KPI strip → Card ×4 in a responsive grid
  • Workers view → Table + Badge + row HoverCard
  • Views → Tabs (Board / Workers / Events / Integrator)
  • New hive → Dialog + Switch + provider ToggleGroup
  • Unit scope → Collapsible file list + CodeBlock diff preview

data-ui hooks (future)

  • hive.run.new, hive.run.pause, hive.unit.retry
  • hive.view.board, hive.view.workers
  • hive.inspector.conductor, hive.integrator.merge
